CRITICAL DESIGN RULES
═══════════════════════════════════════════════════════
1. One action per house per turn — no exceptions.
2. Diplomatic proposals are asynchronous — queued in
   the receiver's inbox, evaluated next turn.
3. Betrayal is unilateral — no proposal needed.
4. No resource sharing between allied houses ever.
5. Territories captured from a defeated house go to
   whoever physically captured each one.
6. Fuzzy Logic outputs scores only — never decisions.
7. MCTS makes all final diplomatic decisions.
8. Greedy is used as MCTS rollout opponent model only
   — not random rollouts.

def evaluate(house, enemies, map):
    own_territory_score = sum(
        t.resource_value + t.defense_bonus
        for t in house.territories
    )
    throne_bonus = 500 if map.iron_throne in
                          house.territories else 0
    enemy_score = sum(
        sum(t.resource_value for t in e.territories) +
        e.armies * 1.5
        for e in enemies
    )
    return (
        own_territory_score * 2 +
        house.armies * 1.5 +
        house.gold * 0.5 +
        throne_bonus -
        enemy_score
    )

    total = H2.get_military_strength()
            + H3.get_military_strength()
    w2 = H2.get_military_strength() / total
    w3 = H3.get_military_strength() / total
    score = w2 * evaluate(H1, [H2], map)
          + w3 * evaluate(H1, [H3], map)
    COMMENT: heuristic approximation — opponent
    interactions evaluated independently.

    score = evaluate(H1, [H2, H3], map)

═══════════════════════════════════════════════════════

2. Paranoid Minimax: assumes full coalition cooperation

   only, not future trajectory.
